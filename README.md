# LTSCX-1842

Driving Business Value through Services as Code, a Cisco Live lightning talk.

## View the presentation

[Open the presentation on Cisco GitHub Pages](https://wwwin-github.cisco.com/pages/kribandi/ltscx-1842/).
Cisco network or VPN access and GitHub authentication may be required.

Use the arrow keys to navigate slides and animation steps. Press `S` for speaker
notes or `F` for fullscreen.

## Publishing

GitHub Pages publishes the repository root from the `master` branch. Commit and
push presentation updates to `master` to redeploy; no local build is required.
The root `.nojekyll` file disables Jekyll processing.

Keep local asset paths relative to `index.html` so they resolve under
`/pages/kribandi/ltscx-1842/`. Reveal.js, Lucide, and fonts load from external CDNs
and require internet access.
